## 💻 Local Development Setup

To run this repository locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ananya21-ghosh/Portfolio.git
   cd Portfolio
   ```

2. **Serve locally using Node / Serve**:
   ```bash
   npx serve -l 9090 .
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:9090` in your web browser.
