My Background & Journey

My background started in graphic design, which taught me to care about visual layout, typography, and user experience. As I progressed into Computer Science, I naturally gravitated toward building the code behind the interface as well. Today, I enjoy working across both sides.

I am currently a 2nd-year student pursuing a B.Tech in Computer Science & Engineering (Data Science) at Future Institute of Engineering and Management (FIEM).

Along with web development, I work as a technical contributor on Handshake AI, evaluating AI model responses, prompt efficiency, and data quality. I completed my schooling at SARADA VIDYAPITH HS with PCM and Computer Science.

  • ✓ Frontend & UI: Building responsive React interfaces with HTML5, CSS3, and JavaScript (ES6+).

I focus on building functional web applications where design and code work together seamlessly:
